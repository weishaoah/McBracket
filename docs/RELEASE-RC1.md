## 4. 「8 强在售」措辞核查结论

全仓检索「在售 / 实时」共 30 处，逐一核对后结论：**无不实表述，未做改动。**

- 页面文案只说「8 款餐品」「本期八强」，从未声称 8 款当前全部在售；
- 每款价格旁标注「官方核价 / 菜单参考价」，培根安格斯明确为菜单参考价 + 10-14 采集日期；
- 「在售」字样只出现在**带时间戳的采集记录**（如「22:00:51 当前时段 6/8 在售」），
  与官方声明「供应状态以官方渠道实时结果为准」一致；
- README 明确写出「培根安格斯厚牛堡在最近两次采集时段都不在门店菜单上」。

   不是随机抽样；已在 README 与 MCP_INTEGRATION 说明。
4. **无真人试玩数据**：发布时 README 不会写任何试玩反馈。
5. **审计期间 agent-browser daemon 数次崩溃**，长链分短链重跑完成；
   证据文件本身完整可复现（脚本入库），但复跑时可能需要重试。
6. **商标合规为自行判断**：项目名含 "Mc"、使用官方商品名，
