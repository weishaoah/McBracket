# McBracket 试玩指南

## 开始前

- 用手机或电脑浏览器打开 Demo 地址（或本地 `npm run dev` 后访问
  http://127.0.0.1:5173/）。
- 不需要登录、不需要账号、不收集任何信息。全程约 1–3 分钟。
- 页面上的价格与营养数据是官方 MCP 的数据快照（非实时），
  以麦当劳官方渠道当前信息为准。

## 玩法

1. **首页**：看到「本期八强」8 款餐品。点「开始我的麦门争霸赛」，
   对阵顺序随机打乱。
2. **对决**：每场出现两款餐品，二选一，点你更喜欢的那款。
   - 点选后才会揭晓两款的价格、热量、蛋白质、钠对比，
     以及各自的数据采集时间。
   - 每场有「下一场」按钮，不点就不会进入下一场。
3. **赛程**：共 7 场 —— 四分之一决赛 4 场、半决赛 2 场、总决赛 1 场。
   页面上方可随时查看当前轮次。
4. **冠军**：7 场点完后出现冠军页，含晋级路线（击败了谁）、
   完整对阵图、被淘汰的 7 款。
5. **冠军卡**：冠军页点「保存冠军卡」，会导出一张竖版 PNG，
   含冠军、价格口径、数据来源与采集时间。保存后可自行分享。
6. **重来**：任何一步都可以点「重新挑战」，对阵顺序重新随机。

## 页面上能看到的口径说明

- 每款餐品价格旁标注「官方核价」或「菜单参考价」。
  「菜单参考价」表示该款在采集时未拿到核价，只展示菜单价及采集日期。
- 某款餐品标注「沿用」，表示它在最近一次采集时未在门店菜单上，
   展示的是上次在售时采集的官方数据。
- 营养数据缺失的字段显示「—」，匹配不上官方营养表的餐品
  显示「暂无可靠数据」。

## 反馈怎么给

能不能完成、卡在哪、愿不愿意重玩或分享。没有反馈也完全没问题。
